1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
Data Studio is a next-generation web application designed for immersive 
data exploration. It allows users to upload datasets (CSV, Excel, JSON) and 
automatically generates summary statistics and interactive 3D statistical 
models. The project features a premium Neo-Brutalist design system with a 
high-performance WebGL rendering engine.

2. TECHNOLOGY STACK (THE ENGINE)
--------------------------------------------------------------------------------
* BACKEND FRAMEWORK: Flask (Python) + Flask-Compress + Gunicorn
  - Handles routing, session management, and Gzip-compressed data transfer.
* DATA PROCESSING: Pandas & NumPy (C-Parsing Engine)
  - Ultra-fast data ingestion and multi-dimensional mathematical calculations.
* VISUALIZATION: Plotly (3D WebGL Engine)
  - Renders 3D Distribution, 3D Trend, 3D Categorical, and 3D Volumetric charts.
* DATABASE & AUTH: Supabase + Background Threading
  - Secure auth with non-blocking cloud storage uploads.
* FRONTEND: HTML5, CSS3, JavaScript (Vanilla) + Bootstrap 5
  - Built with a custom "Modern Neo-Brutalist" design system.
  - AI Insights Engine: Natural language data storytelling.
  - Fully Responsive UI: Optimized for Mobile, Tablet, and Desktop.
  - Interactive Tooltip Engine & High-Performance Loading States.

3. KEY FEATURES
--------------------------------------------------------------------------------
* Secure Login System: Normal Email/Password Sign-up and Sign-in.
* Session Protection: Only logged-in users can access the dashboard.

  - Interactive Tooltips: Hover over any 3D point for precise metrics.
* Neo-Brutalist UI/UX: 
  - High-contrast yellow/black palette.

  - Heartbeat Footer: Animated branding for a premium feel.
* Automated Analytics:

  - High/Low/Avg Extraction: Instant extraction of critical metrics.

4. THE WORKFLOW (STEP-BY-STEP PROCESS)
--------------------------------------------------------------------------------
STEP 1: USER REGISTRATION
- The user signs up at /signup. 
- Supabase Auth stores the credentials securely.

STEP 2: AUTHENTICATION
- User logs in at /login. 
- A secure Flask session is established.

STEP 3: DATA UPLOAD
- On the home page, the user selects a dataset.
- Files are processed directly from memory for maximum speed and security.

STEP 4: 3D ANALYSIS ENGINE
- app.py reads file bytes using the high-speed 'C' mapping engine.
- A background thread starts the Supabase cloud upload (non-blocking).
- Plotly WebGL creates JSON-based high-performance 3D visualizations.

STEP 5: IMMERSIVE DASHBOARD
- The dashboard renders 3D models alongside clean, readable data tables.
- AI Insights provide a structured text narrative of the data's "ground truth."
- Users can naturally explore insights by rotating and interacting with 
  3D models while tables and narrative bullet points provide context.

│   └── charts/         # (Legacy) Standard analysis assets

6. HOW TO RUN THE PROJECT
--------------------------------------------------------------------------------
1. Ensure Python 3.10+ is installed.
2. Activate virtual environment: .\venv\Scripts\activate
3. Install dependencies: pip install -r requirements.txt
4. Configure .env with your Supabase URL, Key, and Secret Key.
5. Run the server (Local): python app.py
6. Run the server (Production): gunicorn app:app
7. Open browser to: http://127.0.0.1:5000

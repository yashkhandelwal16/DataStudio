================================================================================
                      DATA STUDIO. - PROJECT DOCUMENTATION
================================================================================

1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
Data Studio is a next-generation web application designed for immersive 
data exploration. It allows users to upload datasets (CSV, Excel, JSON) and 
automatically generates summary statistics and interactive 3D statistical 
models. The project features a premium Neo-Brutalist design system with a 
high-performance WebGL rendering engine and AI-driven insights.

2. TECHNOLOGY STACK (THE ENGINE)
--------------------------------------------------------------------------------
* BACKEND FRAMEWORK: Flask (Python 3.10+) + Flask-Compress + Gunicorn
  - Handles routing, session management, and Gzip-compressed data transfer.
* DATA PROCESSING: Pandas & NumPy (High-Speed C-Parsing Engine)
  - Ultra-fast data ingestion and multi-dimensional mathematical calculations.
* VISUALIZATION: Plotly (3D WebGL Engine)
  - Renders 3D Distribution, 3D Trend, and 3D Volumetric charts using WebGL.
* DATABASE & AUTH: Supabase (Auth + PostgreSQL)
  - Secure login, OTP verification, and password recovery systems.
* CLOUD STORAGE: Supabase Storage API
  - Non-blocking background threading for cloud dataset archival.
* FRONTEND TOOLING: Vite 7.0 + Node.js
  - High-performance asset bundling and modern development workflow.
* STYLING: CSS3 (Custom Neo-Brutalist Tokens) + Bootstrap 5.3
  - Features glassmorphism, high-contrast palettes, and dark mode support.
* AI ENGINE: Natural Language Insights (Storytelling Engine)
  - Automated narrative generation for descriptive data analysis.

3. KEY FEATURES
--------------------------------------------------------------------------------
* Pro Auth System: 
  - Email/Password login with secure Flask sessions.
  - OTP (One-Time Password) verification for new registrations.
  - Forgot Password / Password Reset workflow via Supabase.
* Multi-format Support: Native processing for .csv, .xlsx, .xls, and .json.
* Advanced Upload UI: 
  - Interactive Drag & Drop zone with scale-up hover effects.
  - Real-time file info display and validation.
* Interactive 3D Visualization: 
  - 360° WebGL Rotation: Explore data from every spatial angle.
  - Interactive Tooltips: Real-time metric extraction on data point hover.
* Neo-Brutalist UI/UX: 
  - Distinctive Yellow/Black high-contrast design.
  - Dark Mode: Full semantic color reversal for low-light environments.
  - Heartbeat branding and marquee animations.
* Performance Optimization:
  - Background Uploads: Storage sync doesn't block the analysis output.
  - Gzip Compression: Reduces JSON visualization weight by ~80%.

4. THE WORKFLOW (STEP-BY-STEP PROCESS)
--------------------------------------------------------------------------------
STEP 1: USER REGISTRATION & VERIFICATION
- User signs up at /signup.
- Supabase sends an OTP; user verifies at /verify-otp to activate account.

STEP 2: AUTHENTICATION
- User logs in at /login.
- A secure session establishes tokens (access/refresh) for cloud interaction.

STEP 3: DATA INGESTION
- User uploads a dataset via the Neo-Brutalist Drag & Drop interface.
- Flask reads the file bytes directly into memory (zero local disk spill).

STEP 4: HYBRID PROCESSING
- DATA ENGINE: Pandas parses the file using the high-speed 'C' engine.
- CLOUD SYNC: A background thread initiates a Supabase Storage upload.
- VIZ ENGINE: Plotly generates WebGL-based JSON models for the dashboard.

STEP 5: IMMERSIVE ANALYSIS
- The dashboard renders 3D models alongside AI-generated narrative insights.
- Users explore the "ground truth" of their data with interactive charts.

5. DIRECTORY STRUCTURE
--------------------------------------------------------------------------------

├── utils/              # Calculation, Insights, and Viz engines
├── static/             # Design tokens, Neo-Brutalist CSS, and Theme JS
├── templates/          # Jinja2 HTML templates (Login, Settings, Dashboard)
├── src/                # Vite source assets and JS modules
├── package.json        # Frontend dependencies (Vite 7.x)
├── requirements.txt    # Backend dependencies (Flask, Pandas, Supabase)
├── Procfile            # Cloud deployment instructions (Render/Heroku)
├── .env                # Environment secrets and API credentials
└── supabase_setup.sql  # Database schema for user data and storage

6. HOW TO RUN THE PROJECT
--------------------------------------------------------------------------------
1. Setup Environments: Install Python 3.10+ and Node.js.
2. Backend: `pip install -r requirements.txt`
3. Frontend: `npm install` followed by `npm run dev` (for Vite tools).
4. Config: Populate `.env` with Supabase and Flask secret keys.
5. Launch: `python app.py` (Local) or `gunicorn app:app` (Prod).
